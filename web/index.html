PROTOTYPE R0 / INTERACTIVE RESEARCH

Affective Conditioning

Explore how a simulated AI state interacts with an observed message state. Change both vectors directly, switch the dynamics model, and inspect every state transition.

Two separate experiments. Simulation uses deterministic example responses. Browser Qwen produces real language-model responses using text-prompts containing the selected affect values. No affect-conditioned LoRA is trained or running here yet. The application does not predict anyone’s emotions.
